# Brand assets

Logos, avatars and banners for use off the website: LinkedIn, Google Workspace,
decks, email signatures.

Everything here is generated by [`scripts/brand/build.mjs`](../scripts/brand/build.mjs),
which is the single source of truth for the brand system. The SVGs and PNGs are
committed as well: the SVGs are the crisp masters, the PNGs are what LinkedIn and
Workspace actually accept, and neither should have to be rebuilt to be used.

## Generate

```bash
pnpm brand
```

Rerun after editing tokens or adding an asset. The build is deterministic, so a
rerun with no source change produces no diff.

### Inter has to be installed

The renderer resolves fonts through the system, and silently substitutes when one
is missing, so `pnpm brand` refuses to run if Inter is not available: an exported
wordmark in the wrong typeface is not something anyone notices until it is next
to the website. Install it from <https://rsms.me/inter/> and rerun.

Embedding the font in the SVG does not work. sharp's SVG renderer ignores an
`@font-face` carrying a base64 woff2 entirely, which is measurable: text in an
embedded family comes out exactly as wide as text in a family that does not
exist.

## How it is built

1. **Tokens** (`TOKENS`): colours, family, weights, letter-spacing. One place to
   change the palette.
2. **Composition primitives**: `wordmarkStacked()`, `monogramVC()`,
   `sloganTwoLines()`, `urlMark()`. Each returns a fragment of SVG.
3. **Asset registry** (`ASSETS`): one entry per file, with output size, clear space,
   background, and the composition to draw.

Canvases are measured rather than declared. Each asset is rendered once on an
oversized probe canvas, its ink bounding box is read back, and only then is a
viewBox computed that holds the content plus its clear space at the required
aspect ratio. This is why an asset cannot clip: the previous generator hardcoded
the canvas and the text origin, and the red period fell off the right edge of the
400x400 logo, which was the file nominated for the LinkedIn company logo.

To add a variant, add an entry to `ASSETS`. To re-tint the brand, change one value
in `TOKENS`.

## Catalogue

### Logos

| Name                              | PNG     | Use                                                                                            |
| --------------------------------- | ------- | ---------------------------------------------------------------------------------------------- |
| `logo-wordmark-stacked`           | 400x400 | Primary square logo, on paper.                                                                 |
| `logo-wordmark-stacked-padded`    | 800x800 | Same logo with generous space, for free-form cropping.                                         |
| `logo-wordmark-stacked-landscape` | 920x260 | Google Workspace custom logo. Transparent background, so Workspace's own chrome shows through. |
| `logo-monogram-vc`                | 400x400 | Compact `VC.` for small renders. Matches the favicon.                                          |

### Avatars

Every platform masks a profile picture to a circle, so these keep the mark inside
the inscribed circle with room to spare. The square logos do not, and lose their
corners.

| Name                    | PNG     | Use                                                           |
| ----------------------- | ------- | ------------------------------------------------------------- |
| `avatar-monogram`       | 800x800 | Profile picture, any platform.                                |
| `avatar-monogram-small` | 400x400 | Same, where 400 is the stated maximum.                        |
| `avatar-wordmark`       | 800x800 | Full wordmark as an avatar, for platforms that show it large. |

### Banners

| Name                           | PNG      | Use                                                                                                                                                                 |
| ------------------------------ | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `banner-slogan`                | 1128x191 | LinkedIn **company page** cover.                                                                                                                                    |
| `banner-linkedin-profile`      | 1584x396 | LinkedIn **personal profile** background. A different image and a different shape; content sits right, because the left is covered by the profile photo on desktop. |
| `banner-wordmark-slogan`       | 2400x600 | Oversized wordmark, slogan and URL, with room to crop by hand.                                                                                                      |
| `banner-wordmark-slogan-tight` | 700x170  | Email signature. Same content, compact, type stays large enough to read at native size.                                                                             |

## Upload specs

| Where                       | Wanted        | Use                                   |
| --------------------------- | ------------- | ------------------------------------- |
| LinkedIn company logo       | 400x400 PNG   | `logo-wordmark-stacked.png`           |
| LinkedIn company cover      | 1128x191 PNG  | `banner-slogan.png`                   |
| LinkedIn profile picture    | 400x400 PNG   | `avatar-monogram-small.png`           |
| LinkedIn profile background | 1584x396 PNG  | `banner-linkedin-profile.png`         |
| Google Workspace logo       | landscape PNG | `logo-wordmark-stacked-landscape.png` |

LinkedIn does not accept SVG. The PNGs are generated at the right dimensions and
upload as they are.

## Tokens

| Token  | Hex       | Where                                                    |
| ------ | --------- | -------------------------------------------------------- |
| paper  | `#fbf4f0` | Backgrounds                                              |
| ink    | `#1a1a1a` | Wordmark, slogan                                         |
| accent | `#d63333` | The period after CONSULTING, the ampersand in the slogan |
| muted  | `#7d7d7d` | URL micro-caps                                           |

Note that these are not identical to the website's palette, which is authored in
oklch and resolves slightly differently (its accent is a touch brighter). Worth
reconciling if the two are ever seen side by side.
